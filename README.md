The final report should be 4 to 5 pages, excluding appendix, and should include:

- Abstract with brief project summary and main results
- Project description and motivation
- Dataset exploration and learning problem formulation
- Data quality, preprocessing, imbalance, or limitation discussion
- Methodology and network architecture
- Loss function, optimizer, and regularization strategy
- At least one advanced method not covered in class
- Training and validation loss curves
- Final metrics and interpretation
- Underfitting / overfitting diagnosis

- Presentation recording link
- Code appendix
